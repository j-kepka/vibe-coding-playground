# Wandmoss Journey

A small fairy-tale platformer. Guide a dwarf wizard through four chapters of
forest, dusk and clouds, find rocket boots, and face the Guardian of the Valley.

[![Play Wandmoss Journey](assets/play-button.svg)](https://j-kepka.github.io/vibe-coding-playground/02-wandmoss-journey/)

![Wandmoss Journey — Dusk Trail, the second chapter](docs/screenshots/wandmoss-journey-dusk.png)

**Move:** ← → or A/D · **Jump:** Space · **Cast:** X · **Rocket boots:** C · **Pause:** P

English, German and Polish. Touch controls on mobile. Enable sound with **♫**;
use the corner icon for fullscreen and **Escape** to return.

To play offline, open `index.html` in a modern browser. Keep the game files
together; no installation or build is needed.
