# Wandmoss Journey — official trademark-register review

**Checked:** 2026-10-10  
**Checked by:** Codex  
**Scope:** Bounded live-register review before publication; full title, distinctive root and specified spacing/spelling variants

**Result:** No matching record was found for **Wandmoss Journey** or the five
core inputs below in the completed queries in EUIPO, WIPO, UPRP, DPMA and
USPTO. The additional near roots returned no records where successfully
queried. No concrete conflicting registration was identified in this scope.
The defined P0 register-review task is complete with the access and coverage
limits below. This is not worldwide legal clearance, a registration of the
name, or a finding that every similar sign is harmless.

The [structured audit](WANDMOSS_TRADEMARK_AUDIT.json) retains submitted fields,
operators, query echoes/payloads, result counts, controls, source URLs,
timestamps and corrections. It excludes copied full-page text and temporary
browser artifacts. The [earlier candidate screening](REPLACEMENT_NAME_SCREENING.md)
remains the record of the web searches preceding selection of the title.

## Names and relevant goods/services

The five core inputs were **Wandmoss Journey**, **Wandmoss**, **Wand Moss**,
**Wandmos** and **Wand Moss Journey**. The additional near roots were
**Wandermoss** and **Wondermoss**. DPMA also received the prefix query
`Wandmoss*`. These are bounded textual variants, not every possible visual,
phonetic or conceptual similarity.

The game is downloadable software and is planned for browser hosting. Relevant
Nice categories are [Class 9](https://nclpub.wipo.int/enfr/?class_number=9&lang=en&menulang=en&mode=flat&pagination=no&version=20260101)
for recorded/downloadable game software and [Class 41](https://nclpub.wipo.int/enfr/?class_number=41&lang=en&menulang=en&mode=flat&pagination=no&version=20260101)
for online game services. Searches started without class restrictions so
potential records were not excluded by an overly narrow filter. Goods/services
outside the same class can still be related; classes alone do not determine
confusion. [USPTO search guidance](https://www.uspto.gov/trademarks/search/federal-trademark-searching)
explains this distinction.

**EUIPO:** Basic text searches returned explicit no-result notices and
matching submitted text/URL for all seven title/root/near-root queries, without
Nice-class or status restrictions. The control included a registered Nintendo
record in Classes 9 and 28.

**WIPO:** Embedded searches returned zero for the single-word roots Wandmoss,
Wandmos, Wandermoss and Wondermoss. Verified **Match exact expression / Terms**
searches returned zero for Wandmoss Journey, Wand Moss and Wand Moss Journey.
The initial Embedded multiword searches returned broad token results
(11,518 / 4,389 / 15,907); those are not counts of matching full titles.

**UPRP:** The direct advanced search worked during this review. Name/Title
**CONTAINS** submissions used trademark type `pwpTypes=[1]` and the BUP/WUP/
E-register collections `[1,2,3]`, without class/status restrictions. Codex
verified native request payloads, actual submitted values and result echoes.
The interface states that its bibliographic trademark records start at
application Z.075001 and granted rights at R.000118. This successful review
does not retrospectively clear the different names that the earlier audit
could not query.

**DPMA:** German national, Union and international mark datasets were selected,
without an in-force-only restriction. Fresh server expressions verified the
requested terms. Separate root searches included `kl=9` and `kl=41`, both
returning zero. Other databases were checked separately because DPMA does
not guarantee complete/correct EM/IR data and expressly does not offer a true
similarity search. [DPMA guidance](https://www.dpma.de/english/trade_marks/trade_mark_search/index.html)
defines those limits.

**USPTO:** Completed queries were `CM:"Wandmoss Journey"`, `CM:Wandmoss`,
`CM:"Wand Moss"`, `CM:Wandmos` and `CM:"Wand Moss Journey"`, with all classes
and both live/dead records included. The emitted server query strings matched
the inputs. The phrase control returned six live registered, one live pending,
six dead cancelled and one dead abandoned records. CM phrase searches can
match a phrase within a longer mark; they do not require an identical whole
mark. With zero all-class results there were no Class 009/041 candidates for
these five inputs; no separate completed class-filter query is claimed.

## Corrections and access limits

- Initial DPMA inputs concatenated previous text or retained a stale query
  result. These attempts were discarded. Corrected submissions verified exact
  field values, fresh server query echoes and the working positive control.
- UPRP initially failed to submit its control. Blur/activation handling was
  corrected, and both positive and differently shaped no-result responses
  were verified before counting the final rows.
- WIPO's first attempt to change matching strategy left Embedded selected.
  Codex detected this in the actual strategy/query structure, corrected native
  selection and retained only verified Terms results as phrase searches.
- USPTO's basic Wordmark multiword handling was too broad for the intended
  phrase checks; Codex reran them with the field-tag builder. After the five
  completed inputs, a wildcard attempt failed and a fresh diagnostic returned
  CloudFront HTTP 403. Wandermoss, Wondermoss and further wildcard/class
  expansions were not completed there. No access-control bypass was attempted.
- TMview returned its access-error page. This is recorded as unavailable,
  never as a zero-result search. Initial local browser launches also required
  approved execution outside the shell sandbox; research used normal browser
  timing and created no screenshots.

## Related public use and interpretation

[Animal Magica's creator site](https://www.animalmagica.com/about/) uses
**Wandermoss** as a fictional place in its fantasy setting. This contextual
near-name use was retained and prompted the extra root checks. It is not an
identified exact-title game or a returned trademark record in the completed
queries. The review does not decide whether any unregistered right exists or
whether two signs are legally confusing.

The practical finding is **no concrete registered collision identified in the
completed, stated searches**. The review does not cover every jurisdiction,
unpublished application, update delay, company/title/domain register,
figurative mark or common-law use. Ordinary Journey/Moss/Wand marks were not
exhaustively reviewed as a separate similarity exercise.
[WIPO's coverage guidance](https://www.wipo.int/en/web/global-brand-database)
notes that its collections do not replace relevant national/regional searches;
[USPTO's comprehensive-search guidance](https://www.uspto.gov/trademarks/search/comprehensive-clearance-search-similar-trademarks)
also distinguishes federal records from other sources of earlier rights.

The owner selected the title and retains publication and name-risk decisions.
No trademark was filed, no third party was contacted, and no licence or game
file was changed during this research iteration.
